📘 Introduction

In this project, we created a smart home system that allows control over 14 devices and 1 air conditioner (AC) using an ESP32 microcontroller. The system includes EEPROM functionality, which retains the state of all devices even after a sudden power loss. With Alexa integration, users can control lights, fans, tube lights, AC, and more using voice commands and monitor the real-time status through the Alexa app.

⚙️ How It Works

The ESP32 serves as the main controller for the entire smart home system. Each room has a 4-channel relay module, which controls the devices (e.g., lights, fans, etc.). The ESP32 sends signals to the relay modules based on user commands.

  1. Voice Control: Integrated with Alexa, users can control devices using voice commands.
  2. Real-time Monitoring: The status of each device is displayed and controlled through the Alexa app.
  3. EEPROM Functionality: In case of a power failure, the system retains the state of each device, ensuring continuity once power is restored.
  4. Centralized Control: A central controller manages all room relays, reducing wiring complexity.

🔌 Components Required

  • ESP32 (central controller with Wi-Fi functionality)
  • 4-Channel Relay Modules (one per room)
  • EEPROM (to store device states)
  • Alexa-compatible devices
  • AC Module
  • Power Supply (5V and 12V)

🛠️ Step-by-Step Guide

Step 1: Gather Components

Collect all the components listed above, ensuring you have an ESP32, relay modules, EEPROM, and Alexa-compatible devices.

Step 2: Build the Circuit Prototype

Start by connecting the ESP32 to the 4-channel relay modules. Wire each room’s module to the central ESP32 controller.

Step 3: Program the ESP32

Upload the code to the ESP32. The code should include the logic for relay control, Alexa voice integration, and EEPROM state retention.

Step 4: Connect to Alexa

Set up the ESP32 to communicate with Alexa. Ensure that each device is properly recognized in the Alexa app.

Step 5: Test the System

Test each room by controlling devices with voice commands and the Alexa app. Ensure that the EEPROM correctly restores the device states after a power cut.
